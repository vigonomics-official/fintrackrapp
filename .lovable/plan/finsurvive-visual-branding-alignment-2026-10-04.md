# FinSurvive visual branding alignment

## Scope
- Create one reusable FinSurvive mark based on the app’s existing emerald/teal gradient and rupee symbol.
- Use that mark consistently in the public header/footer, login/signup presentation, signed-in sidebar, About page, and authenticated loading screen.
- Replace the default favicon with a matching lightweight FinSurvive favicon.
- Keep all layout, navigation, functionality, authentication, data, calculations, and AI behavior unchanged.
- Do not add PWA files because the project currently has no PWA manifest or PWA icon set.

## Verification
- Confirm no user-visible legacy brand references remain while preserving legacy domains, emails, and compatibility keys.
- Run typecheck and production build.
- Inspect the landing page, login, signup, loading state, Dashboard, Expenses, Planner, Insights, Profile, AI Coach, and About at mobile and desktop sizes for consistent branding and layout.
